# 10 - 权限配置

## 概述

Claude Code 支持细粒度的权限控制，精确指定代理可以做什么、不可以做什么。权限设置可以提交到版本控制并分发给团队成员。

## 权限系统

### 分层权限

| 工具类型 | 示例 | 需要批准 | "不再询问"行为 |
|---------|------|---------|---------------|
| 只读操作 | 文件读取、搜索 | 否 | 不适用 |
| Bash 命令 | Shell 执行 | 是 | 按项目和命令永久生效 |
| 文件修改 | 编辑/写入文件 | 是 | 当前会话有效 |

## 管理权限

使用 `/permissions` 查看和管理权限规则：

- **Allow** - Claude 无需批准即可使用
- **Ask** - 每次使用都需确认
- **Deny** - 禁止使用

**评估顺序**：deny → ask → allow（第一个匹配的规则生效）

## 权限模式

| 模式 | 说明 |
|------|------|
| `default` | 标准行为：首次使用每种工具时提示 |
| `acceptEdits` | 自动接受文件编辑权限 |
| `plan` | 计划模式：可分析但不能修改文件或执行命令 |
| `auto` | 自动批准工具调用，后台安全检查验证操作符合请求 |
| `dontAsk` | 自动拒绝未预授权的工具 |
| `bypassPermissions` | 跳过权限提示（保护目录除外） |

**警告**：`bypassPermissions` 跳过权限提示，仅在隔离环境使用。

### 禁用模式

```json
{
  "permissions": {
    "disableBypassPermissionsMode": "disable",
    "disableAutoMode": "disable"
  }
}
```

## 权限规则语法

### 匹配所有使用

```
Bash        # 匹配所有 Bash 命令
WebFetch    # 匹配所有网页获取
Read        # 匹配所有文件读取
```

### 使用说明符

```
Bash(npm run build)           # 精确匹配
Read(./.env)                  # 匹配特定文件
WebFetch(domain:example.com)  # 匹配特定域名
```

### 通配符模式

```json
{
  "permissions": {
    "allow": [
      "Bash(npm run *)",
      "Bash(git commit *)",
      "Bash(git * main)",
      "Bash(* --version)",
      "Bash(* --help *)"
    ],
    "deny": [
      "Bash(git push *)"
    ]
  }
}
```

## 工具特定规则

### Bash

```json
{
  "permissions": {
    "allow": [
      "Bash(npm run build)",      // 精确匹配
      "Bash(npm run test *)",     // 前缀匹配
      "Bash(npm *)",              // npm 开头的命令
      "Bash(* install)",          // install 结尾的命令
      "Bash(git * main)"          // git ... main
    ]
  }
}
```

**注意**：
- `Bash(ls *)` 匹配 `ls -la` 但不匹配 `lsof`
- `Bash(ls*)` 匹配 `ls -la` 和 `lsof`

### Read 和 Edit

遵循 gitignore 规范：

| 模式 | 含义 | 示例 |
|------|------|------|
| `//path` | 文件系统根目录的绝对路径 | `Read(//Users/alice/secrets/**)` |
| `~/path` | 用户主目录 | `Read(~/Documents/*.pdf)` |
| `/path` | 相对于项目根目录 | `Edit(/src/**/*.ts)` |
| `path` 或 `./path` | 相对于当前目录 | `Read(*.env)` |

**示例**：

```json
{
  "permissions": {
    "allow": [
      "Read",
      "Edit(/src/**)"
    ],
    "deny": [
      "Read(./.env)",
      "Read(~/.ssh/*)",
      "Edit(//etc/*)"
    ]
  }
}
```

### WebFetch

```json
{
  "permissions": {
    "allow": [
      "WebFetch(domain:github.com)",
      "WebFetch(domain:docs.python.org)"
    ],
    "deny": [
      "WebFetch(domain:*.internal.company.com)"
    ]
  }
}
```

### MCP 工具

```json
{
  "permissions": {
    "allow": [
      "mcp__puppeteer",
      "mcp__puppeteer__*",
      "mcp__github__search_repositories"
    ],
    "deny": [
      "mcp__github__create_repository"
    ]
  }
}
```

### 子代理

```json
{
  "permissions": {
    "deny": [
      "Agent(Explore)",
      "Agent(my-custom-agent)"
    ]
  }
}
```

## 使用 Hooks 扩展权限

PreToolUse hooks 在权限提示前运行，可以：

- 拒绝工具调用
- 强制提示用户
- 跳过提示让调用继续

```json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Bash",
        "hooks": [
          {
            "type": "command",
            "command": "./scripts/validate-command.sh"
          }
        ]
      }
    ]
  }
}
```

## 工作目录

默认只能访问启动目录的文件：

```bash
# 启动时添加
claude --add-dir /path/to/other

# 会话中添加
/add-dir /path/to/other

# 配置中添加
```

```json
{
  "additionalDirectories": [
    "/shared/components",
    "~/common-utils"
  ]
}
```

## 沙盒与权限的关系

- **权限** - 控制 Claude 可用工具和可访问资源
- **沙盒** - OS 级别的文件系统和网络隔离（仅 Bash）

**防御深度**：
- 权限拒绝规则阻止尝试访问
- 沙盒限制阻止 Bash 命令越界

## 托管设置

企业管理员可部署不可覆盖的设置：

### 托管专属设置

| 设置 | 说明 |
|------|------|
| `allowManagedPermissionRulesOnly` | 仅托管设置中的权限规则生效 |
| `allowManagedHooksOnly` | 仅托管 hooks 生效 |
| `allowManagedMcpServersOnly` | 仅托管 MCP 服务器生效 |
| `disableBypassPermissionsMode` | 禁用 bypassPermissions 模式 |
| `disableAutoMode` | 禁用 auto 模式 |

### 示例

```json
{
  "permissions": {
    "allow": [
      "Bash(npm *)",
      "Bash(git *)",
      "Read",
      "Edit(/src/**)"
    ],
    "deny": [
      "Bash(rm -rf *)",
      "Bash(git push * main)"
    ]
  },
  "allowManagedPermissionRulesOnly": true
}
```

## Auto 模式分类器配置

Auto 模式使用分类器模型决定操作是否安全：

```json
{
  "autoMode": {
    "environment": [
      "组织: Acme Corp. 主要用途: 软件开发",
      "源代码控制: github.example.com/acme-corp",
      "云服务商: AWS, GCP",
      "可信云桶: s3://acme-builds, gs://acme-datasets",
      "内部域名: *.internal.example.com",
      "关键内部服务: Jenkins ci.example.com"
    ],
    "allow": [
      "部署到 staging 命名空间是允许的"
    ],
    "soft_deny": [
      "永不在 infra/terraform/prod/ 外修改生产基础设施"
    ]
  }
}
```

### 查看默认配置

```bash
claude auto-mode defaults  # 默认规则
claude auto-mode config    # 当前生效配置
claude auto-mode critique  # AI 反馈
```

## 设置优先级

1. 托管设置（最高优先级，不可覆盖）
2. 命令行参数
3. 本地项目设置 `.claude/settings.local.json`
4. 共享项目设置 `.claude/settings.json`
5. 用户设置 `~/.claude/settings.json`

**注意**：如果工具在任何级别被拒绝，其他级别无法允许。

## 示例配置

### 开发环境

```json
{
  "permissions": {
    "allow": [
      "Bash(npm *)",
      "Bash(git *)",
      "Bash(node *)",
      "Read",
      "Edit"
    ],
    "deny": [
      "Bash(rm -rf /)",
      "Read(./.env)",
      "Edit(./.env)"
    ]
  }
}
```

### CI/CD 环境

```json
{
  "permissions": {
    "allow": [
      "Bash(npm run *)",
      "Bash(git checkout *)",
      "Read",
      "Edit(/src/**)"
    ],
    "deny": [
      "Bash(git push *)"
    ]
  },
  "defaultMode": "acceptEdits"
}
```

### 只读审查

```json
{
  "permissions": {
    "allow": [
      "Read",
      "Grep",
      "Glob",
      "Bash(git status)",
      "Bash(git diff *)",
      "Bash(git log *)"
    ],
    "deny": [
      "Edit",
      "Write",
      "Bash(git push *)"
    ]
  },
  "defaultMode": "plan"
}
```
