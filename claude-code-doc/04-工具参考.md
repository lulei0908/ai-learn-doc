## 文件操作工具

### Read - 读取文件

读取文件内容，不需要权限确认。

```text
> 读取 src/config/database.ts 的内容
> 查看 package.json 的依赖
> 读取 .env.example 文件
```

**特点：**
- 支持大文件（自动截断）
- 支持多种编码
- 可指定行范围

### Edit - 编辑文件

对现有文件进行精确、定位的编辑，需要权限确认。

```text
> 修改 src/api/handler.ts 第 45 行，将超时从 30s 改为 60s
> 在 main.py 中添加一个新的配置项
> 修复 auth.ts 中的拼写错误
```

**特点：**
- 精确匹配替换（不改变其他内容）
- 比完整文件重写更安全
- "Yes, don't ask again" 在会话内有效

### Write - 写入文件

创建新文件或完全覆盖现有文件，需要权限确认。

```text
> 创建 src/utils/date.ts，包含日期格式化函数
> 创建 tests/api/handler.test.ts
```

**特点：**
- 整个文件一次性写入
- 适合创建新文件或完全重构

### Glob - 文件匹配

基于模式匹配查找文件，不需要权限确认。

```text
> 找到所有 .test.ts 文件
> 列出 src/components 下的所有组件
> 查找所有配置文件（*.json, *.yaml, *.toml）
```

### Grep - 内容搜索

在文件内容中搜索特定模式，不需要权限确认。

```text
> 搜索所有使用 deprecated API 的地方
> 查找所有 TODO 和 FIXME 注释
> 搜索包含 "password" 的文件
```

**特点：**
- 支持正则表达式
- 可指定文件类型过滤
- 返回匹配行和上下文

## 执行工具

### Bash - Shell 命令

在环境中执行 Shell 命令，**需要权限确认**。

```text
> 运行 npm test
> 执行 git status
> 安装依赖 npm install axios
> 查看 Node.js 版本
```

**Bash 工具行为：**

- 每个命令在独立进程中运行
- **工作目录跨命令保持**
- **环境变量不跨命令保持**（需要 `export` 或使用 `CLAUDE_ENV_FILE`）
- 设置 `CLAUDE_BASH_MAINTAIN_PROJECT_WORKING_DIR=1` 可在每次命令后重置到项目目录

**持久化环境变量：**

```bash
# 方式一：使用 CLAUDE_ENV_FILE
export CLAUDE_ENV_FILE=~/.claude-env.sh
echo "export MY_VAR=value" >> ~/.claude-env.sh

# 方式二：使用 SessionStart Hook（动态注入）
# 详见 Hooks 文档
```

### PowerShell - PowerShell 命令（Windows）

在 Windows 上执行 PowerShell 命令，需要启用。

```json
// settings.json
{
  "env": {
    "CLAUDE_CODE_USE_POWERSHELL_TOOL": "1"
  }
}
```

## 代理工具

### Agent - 子代理

生成独立的子代理来处理特定任务，每个子代理有自己的上下文窗口。

```text
> 使用子代理来搜索和理解代码库结构
> 让 Explore 代理分析认证模块
```

**特点：**
- 独立上下文窗口
- 自定义系统提示
- 特定工具访问限制
- 不会污染主对话上下文

### AskUserQuestion - 用户提问

向用户展示多选问题，用于收集需求或消除歧义。

```
Claude: 你想要使用哪种状态管理方案？
  1. Redux
  2. Zustand
  3. Jotai
  4. Context API
```

## 定时任务工具

### CronCreate - 创建定时任务

在当前会话内创建定时任务（会话结束后消失）。

```text
> 每 5 分钟检查一次部署状态
> 1 小时后提醒我审查 PR
```

### CronList / CronDelete - 管理定时任务

```text
> 列出所有定时任务
> 删除定时任务 2
```

## 计划模式工具

### EnterPlanMode - 进入计划模式

### ExitPlanMode - 退出计划模式

## 工具权限控制

### 默认权限规则

| 工具类别 | 需要确认 | "不再询问" 行为 |
|---------|---------|---------------|
| 只读工具（Read, Grep, Glob） | 否 | 不适用 |
| Bash 命令 | 是 | 按项目目录和命令永久生效 |
| 文件修改（Edit, Write） | 是 | 当前会话内有效 |

### 权限配置

```json
// settings.json
{
  "permissions": {
    "allow": [
      "Bash(npm run *)",
      "Bash(git *)",
      "Bash(* --version)",
      "Read",
      "WebFetch(domain:docs.python.org)"
    ],
    "deny": [
      "Bash(rm -rf *)",
      "Bash(git push * main)",
      "Edit(./.env)"
    ]
  }
}
```

### MCP 工具权限

```json
{
  "permissions": {
    "allow": [
      "mcp__github__search_repositories",
      "mcp__filesystem__read_file"
    ],
    "deny": [
      "mcp__github__create_repository"
    ]
  }
}
```
